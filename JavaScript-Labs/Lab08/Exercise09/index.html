Exercise 8.9 – Browser Console and Debugging

Làm quen với Browser Console: console.log/info/warn/error, console.table, console.group, console.time, bắt lỗi bằng try/catch và dừng chương trình bằng debugger.

Thực hành với Console

Mở DevTools (F12) → tab Console, sau đó bấm các nút.

    Gợi ý kiểm tra mã

    1. Tab Console: xem log, cảnh báo, lỗi (màu đỏ) kèm tên file và số dòng.
    2. Tab Sources: bấm số dòng để đặt breakpoint, bấm lại nút để dừng, dùng F10/F11 chạy từng bước.
    3. Gõ trực tiếp vào Console, ví dụ typeof document hoặc document.title.
