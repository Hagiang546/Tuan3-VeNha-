Lab 08 – JavaScript 1: Language Foundations

Làm quen cú pháp JavaScript, biến, kiểu dữ liệu, hàm, String, Date, Array, Object và Browser Console.

  • 8.1
    Enabling/Disabling JavaScript

    Kiểm tra trạng thái JavaScript của trình duyệt: khi script chạy, trang đổi sang "BẬT"; khi tắt JavaScript, trang giữ nội dung mặc định và hiện thông báo trong thẻ <noscript>.

    Mở
  • 8.2
    Embedding JavaScript (inline, internal, external)

    Nhúng JavaScript vào HTML bằng ba cách: thuộc tính inline (onclick), thẻ <script> trong trang và file script.js bên ngoài; kết hợp alert và console.log.

    Mở
  • 8.3
    Variables, Data Types and Operators

    Khai báo biến với let/const/var, quan sát kiểu dữ liệu bằng typeof, thử các toán tử số học và so sánh (== và ===), rồi tính tiền đơn hàng có giảm giá và VAT.

    Mở
  • 8.4
    Functions and Control Structures

    Viết hàm tính phí vận chuyển bằng if/switch, hàm có tham số mặc định tính thành tiền, và dùng vòng lặp for/while (tổng 1..n, bảng nhân, FizzBuzz).

    Mở
  • 8.5
    Working with Strings

    Dùng các phương thức của String (length, trim, toUpperCase, includes, indexOf, slice, replace, split…) và viết hàm tạo slug từ tên sản phẩm có dấu tiếng Việt.

    Mở
  • 8.6
    Working with Dates

    Dùng đối tượng Date để hiển thị đồng hồ theo định dạng Việt Nam, tính ngày giao hàng dự kiến bằng setDate và đếm ngược số ngày đến một ngày khuyến mãi.

    Mở
  • 8.7
    Working with Arrays

    Quản lý danh sách sản phẩm bằng mảng: push/pop/unshift/shift, sort, filter, map, reduce và find; mỗi thao tác cập nhật bảng hiển thị.

    Mở
  • 8.8
    Working with Objects

    Xây dựng đối tượng sản phẩm có thuộc tính và phương thức (this), duyệt bằng Object.keys/entries, chuyển sang JSON, dùng destructuring/spread và đối tượng giỏ hàng.

    Mở
  • 8.9
    Browser Console and Debugging

    Làm quen với Browser Console: console.log/info/warn/error, console.table, console.group, console.time, bắt lỗi bằng try/catch và dừng chương trình bằng debugger.
