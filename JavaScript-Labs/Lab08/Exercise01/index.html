Exercise 8.1 – Enabling/Disabling JavaScript

Kiểm tra trạng thái JavaScript của trình duyệt: khi script chạy, trang đổi sang "BẬT"; khi tắt JavaScript, trang giữ nội dung mặc định và hiện thông báo trong thẻ <noscript>.

Kết quả kiểm tra

Trạng thái: JavaScript đang TẮT

Cách bật/tắt JavaScript trong Chrome

  1. Mở trang này rồi nhấn F12 để mở DevTools.
  2. Nhấn Ctrl+Shift+P, gõ Disable JavaScript rồi nhấn Enter.
  3. Tải lại trang (F5): dòng trạng thái giữ chữ TẮT và hiện thông báo noscript.
  4. Làm lại bước 2 với Enable JavaScript để bật lại.
