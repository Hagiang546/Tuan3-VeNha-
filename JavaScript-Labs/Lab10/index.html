Lab 10 – JavaScript 3: jQuery

Dùng jQuery: selectors, sự kiện, thao tác DOM, hiệu ứng, hoạt ảnh và yêu cầu GET với jqXHR.

  • 10.1
    Installing and Using jQuery

    Cài đặt jQuery qua CDN (kèm bản dự phòng từ cdnjs), kiểm tra phiên bản bằng $.fn.jquery, dùng $(document).ready và đổi nội dung phần tử bằng jQuery.

    Mở
  • 10.2
    jQuery Selectors

    Dùng bộ chọn jQuery: theo thẻ, id, class, con trực tiếp, thuộc tính và các bộ lọc :first, :last, :even, :odd, :contains, :not; kết quả được tô sáng và đếm bằng .length.

    Mở
  • 10.3
    jQuery Events

    Xử lý sự kiện bằng jQuery: tìm kiếm trực tiếp với keyup, click chọn mục, hover bằng mouseenter/mouseleave, uỷ quyền sự kiện với on(), one() và off().

    Mở
  • 10.4
    Adding and Manipulating DOM Elements

    Thao tác DOM bằng jQuery: append, prepend, before, after, clone, html/text, remove và empty trên danh sách giỏ hàng.

    Mở
  • 10.5
    jQuery Effects (show/hide, fade, slide)

    Dùng hiệu ứng ẩn/hiện của jQuery: hide/show/toggle, fadeIn/fadeOut/fadeTo, slideUp/slideDown/slideToggle với tốc độ tuỳ chọn và hàm callback; áp dụng slideToggle cho mục câu hỏi thường gặp.

    Mở
  • 10.6
    Simple jQuery Animation

    Tạo hoạt ảnh bằng animate(): di chuyển, phóng to, làm mờ, nối nhiều hiệu ứng với delay (hàng đợi), dừng bằng stop(); thêm hiệu ứng nảy cho số lượng trên giỏ hàng.

    Mở
  • 10.7
    GET Requests and jqXHR

    Gửi yêu cầu GET bằng $.get và $.getJSON để đọc dữ liệu sản phẩm (products.json) và một API công khai; xử lý kết quả bằng done/fail/always và đọc thông tin từ đối tượng jqXHR (status, statusText, readyState, header).

    Mở
