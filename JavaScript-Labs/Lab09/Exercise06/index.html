    Công cụ gỡ lỗi sự kiện

    1. DevTools → tab Elements → chọn phần tử → ngăn Event Listeners để xem các sự kiện đã gắn.
    2. Trong Console gõ monitorEvents($0, 'click') (với $0 là phần tử đang chọn) để in mọi sự kiện click; unmonitorEvents($0) để dừng.
    3. Đặt breakpoint tại hàm xử lý trong tab Sources rồi bấm vào phần tử.
