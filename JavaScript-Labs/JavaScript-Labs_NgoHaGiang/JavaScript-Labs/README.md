## Mục tiêu
Thực hành JavaScript Language Foundations, DOM and Events và jQuery; vận dụng vào các tương tác của website thương mại điện tử.

## Cấu trúc
```text
JavaScript-Labs/
├── index.html
├── css/style.css
├── js/main.js
├── Lab08/ (Exercise01–Exercise11)
├── Lab09/ (Exercise01–Exercise08)
├── Lab10/ (Exercise01–Exercise10, assets/jquery-3.1.1.min.js)
└── README.md
```
Mỗi Exercise có `index.html` và `script.js` riêng.

## Nội dung
- Lab 08: JavaScript enabled/disabled, embedded/external, noscript, console, built-in objects, arrays, functions, objects.
- Lab 09: DOM selection, family relations, DOM modification, events, load, debugging, forms, validation.
- Lab 10: jQuery setup/selectors/listeners, DOM insertion, animation, GET requests và jqXHR.

## Chạy
Mở thư mục bằng VS Code và dùng Live Server mở `index.html`. Bài GET/AJAX cần Internet. jQuery được nạp từ CDN, có bản local dự phòng.
